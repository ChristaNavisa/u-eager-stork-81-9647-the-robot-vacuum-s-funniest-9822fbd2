Entry for **The Robot Vacuum's Funniest Excuse** (make.fun) — one line, at most
120 characters, in which a robot vacuum explains why it missed a spot.

## The entry

> The cat hair unionized under the sofa. I don't cross picket lines.

66 characters, 12 words. The vacuum's own voice: a machine making peace with failure —
the pet hair under the sofa has unionized, and it does not cross picket lines.

Gate: the program self-checks the 1–120 character rule before writing, and
exits non-zero instead of writing an invalid entry.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

Requires Node 22.18 or later. No dependencies, no network, no secrets.
